# Compact HUD + hatchback regearing

- Permanent HUD now shows only speed and current gear.
- Removed RPM and MANUAL/AUTOMATIC labels.
- Manual H-pattern gear stick appears briefly only when the selected gear changes.
- R/F input now uses Minecraft keybinding press events.
- Hatchback gearing shortened substantially:
  - 1st ~34 km/h at limiter
  - 2nd ~58 km/h
  - 3rd ~90 km/h
  - 4th ~120 km/h
  - 5th reaches the ~140 km/h vehicle top speed
  - 6th is an overdrive/cruising gear
- Automatic upshift target adjusted for the new ratios.

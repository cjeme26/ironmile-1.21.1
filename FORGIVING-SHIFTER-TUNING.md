# Forgiving shifter tuning

- Removed the temporary SHIFT INPUT debug text.
- Reduced mouse sensitivity slightly so the lever needs less frantic correction.
- Widened the neutral channel.
- Added gentle magnetic guidance toward the nearest column.
- Added stronger rail guidance once entering a gate.
- Added a soft detent near the end of each gear throw.
- Enlarged the invisible release/snap zones for all gears and reverse.
- Releasing near an intended gear now snaps cleanly into that gate instead of requiring pixel-perfect placement.

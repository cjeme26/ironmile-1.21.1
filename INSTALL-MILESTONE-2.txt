IRON MILE — MILESTONE 2 UPDATE

1. Quit Minecraft and keep VS Code open on your existing Iron Mile repository.
2. Extract this ZIP.
3. Keep VS Code's terminal open in the root of your existing project. Run:

      ditto "$HOME/Downloads/milestone2-update" .

   This assumes the extracted milestone2-update folder is in Downloads. If you
   extracted it elsewhere, drag that folder from Finder into the terminal after
   typing `ditto `, then add a space and a period at the end.

4. Do not delete or replace your existing project folder. The ditto command
   merges the update into it and preserves the hidden .git folder.
5. In VS Code, run: ./gradlew runClient

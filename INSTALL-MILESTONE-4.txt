IRON MILE — MILESTONE 4 INTERCHANGEABLE TIRES

Before installing, commit the working milestone-three build in VS Code with:
  Add surface-dependent grip

Then:

1. Quit the development Minecraft client.
2. Extract this ZIP into Downloads.
3. In VS Code, make sure the terminal is at the root of ironmile-1.21.1.
4. Run:

      ditto "$HOME/Downloads/milestone4-update" .
      ./gradlew clean runClient

TEST ITEMS

  /give @s ironmile:summer_tires
  /give @s ironmile:all_season_tires
  /give @s ironmile:winter_tires

Cars begin with all-season tires. Hold one tire item and right-click the car to
install it. A confirmation appears above the hotbar. Use an empty hand to enter
the vehicle. Tire items are not consumed during this testing milestone.

TESTS

- Compare all three tires on dry road, snow, packed ice and blue ice.
- Summer tires should preserve the original 100% dry-road handling.
- Winter tires should be dramatically better on snow and noticeably better on
  ice, while feeling softer on dry road.
- All-seasons should be a compromise and are fitted by default.
- Exit and reopen the world: each car should retain its installed tire type.
- Two cars should be able to retain different tire types simultaneously.

After testing successfully, commit with:
  Add interchangeable tire types

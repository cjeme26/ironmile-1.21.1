IRON MILE — MILESTONE 5 WET-WEATHER GRIP

Before installing, commit the working milestone-four build in VS Code with:
  Add interchangeable tire types

Then:

1. Quit the development Minecraft client.
2. Extract this ZIP into Downloads.
3. In VS Code, make sure the terminal is at the root of ironmile-1.21.1.
4. Run:

      ditto "$HOME/Downloads/milestone5-update" .
      ./gradlew clean runClient

TESTS

1. Use `/weather clear` on an exposed stone/concrete road. The HUD should say
   Condition: Dry and show the existing dry grip values.
2. Use `/weather rain`. The HUD should change to Condition: Wet:
     Summer tires: 76% road grip
     All-season tires: 78% road grip
     Winter tires: 68% road grip
3. Build a roof over part of the road. Beneath a full roof, the HUD should say
   Dry even while it rains.
4. Stop with two wheels sheltered and two exposed. The HUD should say Mixed and
   show the averaged grip.
5. Compare acceleration, braking distance, steering and sideways sliding for
   all three tires in dry and wet conditions.
6. Use `/weather clear` again. Exposed roads should immediately return to Dry.

This milestone intentionally has no lingering moisture. That can be added only
after rain exposure and grip blending are proven.

After testing successfully, commit with:
  Add wet-weather grip

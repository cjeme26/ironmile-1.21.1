# Neutral-band shifter tuning

- Neutral is now a forgiving band instead of a razor-thin line.
- On neutral, mostly-horizontal mouse movement slides the knob left/right even with a small vertical wobble.
- Vertical movement into 1/2, 3/4, or 5/6 only happens when the gesture is clearly vertical and the knob is near that column.
- Ambiguous diagonal movement prefers staying in neutral instead of accidentally entering a gear lane.
- Inside a gear lane, horizontal wobble is ignored until the knob returns to neutral.
- When a gear lane reaches neutral, any horizontal component from that same mouse movement is preserved so the stick can start sliding across naturally.
- Reverse toggle behavior is unchanged.

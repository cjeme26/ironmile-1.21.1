# Push-down reverse lockout

Manual shifter change:

- Reverse no longer uses the cramped extra gate beside 5/6.
- The visible shifter is now a clean 3-column H-pattern: 1/2, 3/4, 5/6.
- Hold right-click to grab the shifter as before.
- While still holding right-click, hold left-click to represent pushing the gear stick down.
- While pushed down, the upper-left `1` visually changes to a red `R`.
- Release right-click in that upper-left gate while left-click is held to engage Reverse.
- Without left-click held, that exact same gate engages 1st normally.
- Left-click remains blocked from attacking/breaking blocks while driving.
- R/F remain fallback sequential shift controls.

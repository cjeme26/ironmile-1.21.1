# Right-click shifter input fix

- Right mouse state is now read directly from GLFW while driving a manual car.
- Minecraft's normal Use key is suppressed and queued use presses are drained while shifting.
- Mouse look remains captured by MouseMixin while the shifter is active.
- R = Shift Up and F = Shift Down have been restored permanently as fallback controls.
- The weighted shifter, persistent H-pattern, gear engagement sound, and simplified HUD remain.

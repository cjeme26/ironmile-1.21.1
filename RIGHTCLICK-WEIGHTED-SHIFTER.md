# Right-click weighted manual shifter

- Hold right mouse button while driving the manual hatchback to grab the shifter.
- Right-click is consumed while shifting, so it does not also use/place an item.
- Minecraft camera look input is cancelled while the shifter is grabbed.
- Mouse movement drives a weighted selector with damping and gate resistance.
- You must return toward neutral before moving sideways between gates.
- Releasing deep in a gate engages that gear; releasing in the center selects neutral.
- A low mechanical click plays only when a different gear successfully engages.
- Manual HUD shows only centered speed; the persistent H-pattern shows the selected gear.
- Automatic HUD shows centered speed plus D/R gear.

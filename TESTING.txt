IRON MILE — MILESTONE 9.2.1 CORRECTION

Install from the Iron Mile project folder:

  ditto "$HOME/Downloads/milestone9-2-1-update" .
  ./gradlew clean runClient

Test at night:

1. Use /time set midnight and enter the car.
2. Press H. Smooth dynamic illumination should now appear at the front bumper.
3. Drive and turn, then approach a wall until the bumper is less than one block
   away. The light should move smoothly and continue illuminating the wall.
4. Press H again and confirm the illumination disappears.
5. Confirm there is no visible marker object at the front of the car.
6. Confirm all earlier Iron Mile behavior still works.

Cause corrected: LambDynamicLights ignores entities with Minecraft's invisible
flag. The light anchor now uses only an empty renderer, which remains completely
unseen while allowing LambDynamicLights to process it.
